# CyberRisk-VAPT-GRC
A beginner-friendly Flask web application for VAPT findings, risk assessment and GRC recommendations.

## Project Overview

CyberRisk is a local web application that helps document VAPT findings,
calculate risk scores and provide basic GRC recommendations.

## Features

- Demo login system
- VAPT finding management
- Likelihood × Impact risk calculation
- Risk classification
- GRC recommendations
- Finding status management
- CSV report export

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Nmap
- VS Code
